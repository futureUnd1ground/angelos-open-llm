# Open LLM — AngelOS

Открытые и совместимые модели в нативных настройках AngelOS: чат, скачивание локальных моделей, цикл инструментов и MCP-мост. Плагин работает в heaven и hell и использует текущую тему системы.

## Установка и первый запрос

Установи ZIP через Community Store (перетащи в поле ZIP). Открой **Настройки → Приложения → Open LLM — AngelOS**.

Для локальной модели:

1. Выбери Ollama и оставь `http://127.0.0.1:11434`.
2. Если Ollama отсутствует, нажми **Установить Ollama**, затем **Запустить сервер**.
3. Выбери Qwen3 4B или введи другой ID и нажми **Скачать и выбрать модель**. Дождись сообщения об успешной загрузке.
4. Напиши запрос в разделе «Агент» или в меню «Выполнить…»: `llm посмотри текущую тему, включи тёмную и проверь результат`.

4B занимает около 2,5 ГБ загрузки и подходит как стартовый вариант для компьютера с 16 ГБ RAM. На CPU ответы могут быть медленными. Более крупные модели требуют больше памяти. **Качество как у Codex не гарантируется:** инструменты дают возможность действовать, а качество планирования и ответов зависит от модели. Плагин управляет рабочим столом; он не является полноценным агентом разработки с доступом к проектам и терминалу.

Runtime Ollama v0.35.1 устанавливается без sudo в `~/.local/share/angelos-open-llm/runtime`. Автоустановка поддерживает x86_64, требует Python 3.10+, zstd, примерно 1,44 ГБ загрузки и минимум 6 ГБ свободного места; официальный архив проверяется по фиксированному SHA-256 перед распаковкой. На других архитектурах установи Ollama самостоятельно. Уже установленный Ollama тоже поддерживается. Модели хранятся в стандартном хранилище Ollama (обычно `~/.ollama/models`). Сервер запускается только явной кнопкой, только на loopback, без автозапуска после входа. Журнал: `~/.local/share/angelos-open-llm/server.log`.

Отмена загрузки прекращает запрос клиента; сервер может продолжать работу. Повторная загрузка того же ID использует уже скачанные слои Ollama. Плагин не удаляет модели или внешний runtime.

## Серверы и протоколы

- **Ollama:** нативные `/api/chat`, `/api/tags`, `/api/pull`.
- **LM Studio, llama.cpp/GGUF, vLLM/SGLang, LocalAI, Jan, KoboldCpp, text-generation-webui:** OpenAI-совместимый `/v1` endpoint. Установку моделей у этих серверов выполняют их приложения.
- **OpenRouter, Hugging Face Inference:** облачные OpenAI-совместимые endpoint с API-ключом.
- **Свой сервер:** любой совместимый endpoint. Укажи URL с базовым путём API, например `http://localhost:8080/v1`.

Пресеты заполняют адреса; они не устанавливают все перечисленные приложения. Совместимость чата и tools зависит от версии сервера, модели и chat template. Для llama.cpp может потребоваться `--jinja`. Если сервер или модель не поддерживает tools, выбери **Только чат**. Облачные API могут требовать оплату провайдера. Плагин не оформляет подписки.

## Инструменты

Чтение: тема, панель, плагины и экраны; окна и рабочие пространства niri; питание; обои из `~/Pictures`; поиск настроек.

Действия: открыть настройки и лаунчер, изменить light/dark/auto, анимации и панель, переключить рабочее пространство, сфокусировать окно, управлять воспроизведением и громкостью, применить обои из `~/Pictures`.

По умолчанию чтение выполняется сразу, изменения ожидают **Применить / Отклонить**. Режим **Автоматические действия AngelOS** разрешает перечисленные изменения без подтверждения. Агент выполняет до 4/8/16/24 обращений к модели за запрос и передаёт результаты инструментов обратно модели. Неизвестные инструменты и неверные аргументы отвергаются. Произвольные команды, чтение личных документов, удаление файлов, публикация и переписка отсутствуют.

Выполненные действия не откатываются при остановке. IPC подтверждает приём команды оболочкой; модель должна повторно проверить состояние для подтверждения фактического изменения.

## Приватность

Промпты, история и результаты инструментов отправляются выбранному серверу. Названия окон могут содержать личную информацию. Для полностью локальной работы используй loopback endpoint. В режиме памяти до 80 текстовых реплик сохраняются локально с правами 600, отдельно для endpoint, модели и характера. Сырые вызовы и результаты инструментов в память не записываются. Сохранённые реплики передаются выбранной модели при следующем разговоре. Память можно отключить; «Новый чат» удаляет память текущего разговора.

Ключи передаются помощнику через stdin, не аргументы процесса; хранятся отдельно в `~/.config/angelos-open-llm/credentials.json` (каталог 700, файл 600), с привязкой к точному URL. Они не включаются в ZIP, настройки плагина или MCP. HTTP redirects для запросов к модели запрещены, чтобы ключ не уходил другому серверу. Локальный HTTP endpoint не требует ключа. Для удалённых серверов используй HTTPS.

## MCP для внешних клиентов

Добавь stdio-сервер в конфигурацию клиента:

```json
{
  "mcpServers": {
    "angelos": {
      "command": "python3",
      "args": ["/home/YOUR_USER/.config/angelos/plugins/open-llm/scripts/mcp.py"]
    }
  }
}
```

По умолчанию доступны только инструменты чтения. Для действий добавь отдельный аргумент `--allow-actions`: их подтверждение тогда зависит от внешнего клиента. Это независимый режим; он не включает автоматические действия в нативном чате. MCP использует JSON-RPC/stdio с построчным JSON; протокол `2024-11-05`.

## Проверки

`python3 -m unittest discover -s tests -v`

Интеграционные тесты используют локальный HTTP-сервер и проверяют оба протокола, цикл инструментов, подтверждение/отклонение, лимит шагов, загрузку, изоляцию ключей и MCP без действий. Проверки не скачивают реальные многогигабайтные модели.

Документация протоколов: [Ollama chat](https://docs.ollama.com/api/chat), [pull](https://docs.ollama.com/api/pull), [Linux runtime](https://docs.ollama.com/linux), [Qwen3](https://ollama.com/library/qwen3), [LM Studio](https://lmstudio.ai/docs/developer/openai-compat), [llama.cpp server](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md), [OpenRouter](https://openrouter.ai/docs/api_reference/overview), [Hugging Face](https://huggingface.co/docs/inference-providers/en/tasks/chat-completion).

## Чат через ангела и демона (1.1.0)

Кликни персонажа → **Open LLM**. Напиши запрос и нажми Enter или «Отправить». Пока модель отвечает, в том же меню доступны статус и остановка; изменения подтверждаются кнопками «Применить / Отклонить». После ответа персонаж показывает текст с отметкой Open LLM. Длинные ответы разбиты на страницы: «Дальше», «Ещё спросить», «Весь чат».

Используется тот же backend, модель и история, что в настройках плагина. Настрой модель заранее. В аду интерфейс остаётся у текущего демона. Ответ не прерывает активную сюжетную сцену; полный текст остаётся в чате. Модель не меняет персонажа или сохранение сюжета.

Требуется версия оболочки с `Angel.registerAssistant` / `unregisterAssistant` (отдельный PR к AngelOS-Dotfiles). На старой оболочке чат в настройках и команда `llm` продолжают работать, но кнопки у персонажа не будет. Отключение плагина убирает кнопку и останавливает запрос.


## Живой помощник (1.2.0)

Ангел общается тепло и естественно, демон — с доброй иронией; в настройках можно выбрать нейтральную манеру. Это инструкция выбранной модели, а не гарантия качества её ответов. Помощник не меняет канон или сохранение игры.

При ожидании ответа персонаж слегка покачивается; после ответа ненадолго оживляет крылья и закрывает глаза; при ошибке меняет позу. Спокойные анимации, перетаскивание и сюжетный переход отключают новые жесты. Никаких автоматических запросов к модели по таймеру: таймеры меняют только локальную анимацию и подпись ожидания.

Память находится в `~/.local/state/angelos-open-llm/` (или XDG_STATE_HOME), каталог 700, файлы 600. Она содержит только ограниченный текст разговора, но ответы модели могут пересказывать сведения рабочего стола. API-ключи из настроек и сырые результаты инструментов туда не записываются. «Новый чат» очищает текущий разговор, включая память характера, от которого он был начат. При отключении памяти существующий файл сохраняется до явного удаления.
